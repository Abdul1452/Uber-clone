# Project instructions

This is a Flutter application backed by Supabase.

## Development rules

- Keep application code under `lib/`.
- Use `supabase_flutter` for Supabase access.
- Read Supabase URL and publishable key from `--dart-define`; never commit
  credentials.
- Run `flutter analyze` and `flutter test` before completing code changes.
- Keep generated platform directories out of manual edits unless the change
  cannot be expressed through Flutter configuration.
